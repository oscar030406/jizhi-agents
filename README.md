# 集智 · 多智能体个性化课程生成与学习系统

输入一句学习需求，几分钟内生成一门完整的课：连贯讲义、交互教具、随堂测验。
生成过程全程可见——讲义在你眼前逐字成稿，多智能体车间的每个环节实时汇报。
进入课堂后是讲义阅读 + AI 师生对话的形态：老师抛检查问题，同学追问、补反例，
你随时可以插话提问。

面向岗位群「大模型应用开发」的企业内训与转岗培训场景（赛题 XH-202630）。

## 它和「让大模型写课件」有什么不同

- **接地拼装，不是转述**。核心事实内容从受控知识库的教材原文直出：模型只负责编排
  和衔接，占位符由程序机械替换为原文，出处标注到段。我们实测过：让模型转述教材，
  学习成效达成率 51%；换成拼装形态是 87%。
- **独立判官审核**。每页内容由异族判官模型逐条核验事实断言，标记的断言打回修订再
  复审，判决徽章随场景展示、可点开看逐条判定。审核在后台跑，不挡课程上台。
- **交付前机械验算**。讲义里的代码块丢进沙箱真跑，数值等式用 AST 白名单复核，
  算错的当场标红。这一步零模型成本，纯程序执行。
- **个性化贯穿全链**。学习者画像决定难度档、讲解深度、类比领域和测验难度带；
  测验成绩回写画像，已掌握的概念在后续选段时跳过。
- **等待期即阅读期**。课程按场景流水线并行生成，第一页可读即进课堂；后续页面
  边生成边直播成稿，等待时间直接用来读。

## 快速开始

环境：Node 20+ / pnpm、Python 3.11+、Windows（启动脚本为 PowerShell；其他平台可按
脚本内容手动起两个服务）。

```powershell
# 1. 前端依赖
cd apps/classroom
pnpm install

# 2. 配置 API Key：复制 .env.example.tzb 为 .env.local，填入硅基流动 Key

# 3. 引擎依赖
cd ../agent-engine
pip install -r requirements.txt

# 4. 知识库数据包（含教材语料，仓库不携带，向项目组索取网盘链接）
#    解压覆盖到 apps/agent-engine/data/

# 5. 一键启动（课堂 :3210 + 引擎 :8001）
cd ../..
.\scripts\start-demo.ps1
```

打开 http://127.0.0.1:3210，在首页输入学习需求即可造课。
没有知识库数据包也能跑：生成自动降级为通识模式，页面如实标注「未接地」。

## 两端联动是怎么设计的

系统有两端：管理端投领域知识，学习端在该领域内学。读代码时抓住三条主线即可。

**1. 领域接入是一条九站流水线**（`apps/agent-engine/backend/services/domain_intake.py`）。
管理端上传一个 zip / 多文件 / 仓库地址，请求路径只落盘秒回 run_id；接收清洗、切块入库、
建索引、知识整理、金标派生、试跑体检、指标复测、个性化注册在后台按依赖图接力，
每一站的进度、产出与失败理由都写进事件流，管理端 run 页照着直播。扫描版 PDF
走视觉模型转写旁路（`backend/rag/pdf_transcribe.py`），图纸只留占位不由模型转述。

**2. 「域」有唯一真源**。流水线第⑧站把新库的中文名、块数、是否够格出货、示例提示词、
是否涉及动手操作写进 `domain_registry.json`；学习端全部域相关界面（画像下拉、造课示例、
域工作区、安全提示层）经同一条链读它：
`lib/server/domain-registry.ts`（读盘）→ `/api/domains`（唯一对外口）→
`lib/knowledge/domain-registry.ts`（内存视图，客户端由根布局的 `DomainRegistryInit` 灌注）。
硬编码表只作历史库兜底，新库不需要改任何前端代码。每门课的域归属同理：
`lib/server/course-domains.ts` 现读磁盘推导，经 `/api/course-domains` 下发。

**3. 学习证据按域分桶**。测验与导学产生的每条证据带 `domain` 字段
（`lib/evidence/`），画像折叠（加权 Beta-Binomial）、掌握门（估计×置信双条件）、
复习排期、错题本全部按当前域取数——换域是切换视角，不同库的学情互不污染。

质量闸不放行时不静默：库不够格标「试运行」不进学习者下拉，覆盖率量不出就列缺口
而不是造比率，判官逐条断言的判定徽章挂在每一页场景上可点开细看。
